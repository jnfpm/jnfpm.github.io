Customer Segmentation & Market Basket Analysis

Unsupervised Machine Learning and association rule mining for customer profiling and purchasing pattern discovery.

Objective

The goal of this project was to segment customers into meaningful groups based on their characteristics and purchasing behaviour, while also identifying product associations that could support targeted marketing, merchandising and cross-selling strategies.

Dataset

The project combines customer information and transactional basket data. Additional customer-level variables were engineered during preprocessing to better represent purchasing behaviour.

  • Customer information
  • Transactional basket data
  • Customer spending behaviour
  • Engineered customer-level features

Methodology

Multiple preprocessing and clustering approaches were explored to identify meaningful customer segments.

  • KNN imputation for missing values
  • Log transformations for skewed variables
  • Standard, Robust and Min-Max scaling
  • K-Means
  • Hierarchical Clustering
  • DBSCAN
  • MeanShift
  • Self-Organizing Maps
  • UMAP and t-SNE visualisation

Market Basket Analysis

Apriori and association rules were used to identify products that frequently occur together in customer transactions.

Cluster-specific purchasing patterns were also analysed, allowing product associations to be explored within different customer segments.

Key Takeaways

The project combined customer segmentation with market basket analysis, demonstrating how clustering and association rules can complement each other when analysing customer behaviour.

Technologies

Python Pandas NumPy Scikit-learn MLxtend UMAP t-SNE Clustering

Pastel de Nata Quality Prediction

Machine Learning classification project predicting the quality of Pastéis de Nata based on recipe and production conditions.

Objective

The objective was to build a Machine Learning model capable of predicting whether a batch of Pastéis de Nata should be classified as OK or KO based on recipe, processing and production conditions.

Dataset

The dataset contains recipe and production variables describing different batches of Pastéis de Nata.

  • Ambient humidity
  • Baking duration
  • Cooling period
  • Cream fat content
  • Egg temperature
  • Egg yolk count
  • Final temperature
  • Lemon zest pH
  • Oven temperature
  • Preheating time
  • Salt ratio
  • Sugar content
  • Vanilla extract

Methodology

A complete Machine Learning pipeline was developed, covering the process from data exploration to final model evaluation.

  • Exploratory data analysis
  • Data cleaning
  • Missing value treatment
  • Feature transformation
  • Categorical encoding
  • Feature selection
  • Train / validation / test split
  • Model comparison
  • Hyperparameter tuning

Models

  • Logistic Regression
  • K-Nearest Neighbours
  • Gaussian Naive Bayes
  • Decision Tree
  • Bagging
  • Random Forest
  • MLP Classifier
  • Gradient Boosting
  • Stacking

Final Model

A tuned Random Forest was selected as the final model because it provided a strong balance between predictive performance, stability and generalisation.

Evaluation

Performance was evaluated using accuracy, precision, recall and F1-score, together with train-versus-validation results to assess generalisation.

Key Takeaways

This project provided practical experience developing an end-to-end classification pipeline, from exploratory analysis and preprocessing to model comparison, hyperparameter tuning and final evaluation.

US Unemployment Forecasting

Time series forecasting using Box-Jenkins methodology and Seasonal ARIMA models in R.

Objective

The objective was to model and forecast the US unemployment rate using classical time series forecasting techniques.

Dataset

The analysis uses the monthly US unemployment rate series from FRED, with the forecasting evaluation focused on pre-pandemic observations.

Methodology

  • Time series exploration
  • Stationarity testing
  • Seasonal differencing
  • Regular differencing
  • ACF and PACF analysis
  • Model identification
  • Model estimation
  • Residual diagnostics
  • Out-of-sample validation

Final Model

The final selected specification was:

SARIMA(2,1,1)(1,1,2)₁₂

Multiple candidate models were compared using information criteria, parameter significance and residual diagnostics before selecting the final model.

Results

0.187 In-sample RMSE
0.132 In-sample MAE
2.54% In-sample MAPE
0.478 Out-of-sample MASE

Diagnostics

The final model showed no significant residual autocorrelation according to the Ljung-Box diagnostic, supporting the adequacy of the selected specification.

Key Takeaways

This project provided practical experience with the Box-Jenkins methodology, stationarity analysis, model identification, diagnostics and out-of-sample forecasting.

The out-of-sample MASE below 1 indicates performance better than the corresponding naive benchmark.

R Time Series SARIMA Forecasting Box-Jenkins FRED

Parkinson's Disease Neural Network Optimization

Metaheuristic optimization of neural network weights for Parkinson's disease classification.

Objective

This project investigated whether metaheuristic optimization algorithms could improve neural network performance when optimizing network weights for Parkinson's disease classification.

Dataset

The project uses the UCI Parkinson's dataset, containing voice and acoustic measurements used to distinguish healthy individuals from patients with Parkinson's disease.

The model uses 21 input features for binary classification.

Neural Network

The baseline architecture is a Multi-Layer Perceptron with 21 input features, a hidden layer containing 100 ReLU neurons, and a binary output.

The baseline model uses Adam optimisation, while the experimental approaches optimise network weights using metaheuristic algorithms.

Optimization Algorithms

  • Genetic Algorithm (GA) — population-based evolutionary optimization.
  • Grey Wolf Optimizer (GWO) — swarm-based continuous optimization.

L2 Regularization

L2-regularized variants were also investigated to encourage smaller network weights and improve generalisation.

Experimental Setup

  • 21 input features
  • 100-neuron hidden layer
  • ReLU activation
  • Binary classification
  • Genetic Algorithm population of 50
  • Grey Wolf Optimizer pack of 30
  • Convergence analysis
  • Validation and test evaluation

Key Findings

  • GA provided strong exploration but converged more slowly.
  • GWO showed faster convergence in the experiments.
  • L2 regularisation helped control overfitting and encouraged smaller weights.
  • The optimized approaches generally improved validation performance compared with the baseline.
