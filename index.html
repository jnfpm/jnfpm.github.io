Customer Segmentation & Market Basket Analysis

Unsupervised Machine Learning and association rule mining for customer profiling and purchasing pattern discovery.

Objective

The goal of this project was to segment customers into meaningful groups based on their characteristics and purchasing behaviour, while also identifying product associations that could support targeted marketing, merchandising and cross-selling strategies.

Dataset

The project combines customer information and transactional basket data. Several engineered variables were created during preprocessing to better represent customer behaviour.

  • Customer information
  • Transactional basket data
  • Customer spending and purchasing behaviour
  • Engineered customer-level features

Methodology

Several preprocessing and clustering techniques were explored before selecting the most appropriate segmentation approach.

  • KNN imputation for missing values
  • Log transformations for skewed variables
  • Standard, Robust and Min-Max scaling
  • K-Means clustering
  • Hierarchical clustering
  • DBSCAN
  • MeanShift
  • Self-Organizing Maps
  • UMAP and t-SNE visualisation

Market Basket Analysis

Apriori and association rules were used to identify products that frequently occur together in customer transactions.

The analysis also explored cluster-specific purchasing patterns, allowing product associations to be studied within different customer segments.

Key Takeaways

This project combined customer segmentation with market basket analysis, showing how unsupervised learning and association rules can complement each other when analysing customer behaviour.

Technologies

Python Pandas NumPy Scikit-learn MLxtend UMAP t-SNE Clustering

Pastel de Nata Quality Prediction

Machine Learning classification project predicting the quality of Pastéis de Nata based on recipe and production conditions.

Objective

The objective was to build a Machine Learning model capable of predicting whether a batch of Pastéis de Nata should be classified as OK or KO based on recipe, processing and production conditions.

Dataset

The dataset contains recipe and production variables describing different batches of Pastéis de Nata.

  • Ambient humidity
  • Baking duration
  • Cooling period
  • Cream fat content
  • Egg temperature
  • Egg yolk count
  • Final temperature
  • Oven temperature
  • Preheating time
  • Sugar content
  • Salt ratio
  • Vanilla extract

Methodology

A complete Machine Learning pipeline was developed, including exploratory analysis, preprocessing, feature selection, model comparison and hyperparameter tuning.

  • Data cleaning
  • Missing value treatment
  • Feature transformation
  • Categorical encoding
  • Train / validation / test split
  • Model comparison
  • Hyperparameter tuning

Models

Several classification algorithms were compared:

  • Logistic Regression
  • K-Nearest Neighbours
  • Gaussian Naive Bayes
  • Decision Tree
  • Bagging
  • Random Forest
  • MLP Classifier
  • Gradient Boosting
  • Stacking

Final Model

The tuned Random Forest model was selected as the final model because it provided a strong balance between predictive performance, stability and generalisation.

Evaluation

Model performance was evaluated using accuracy, precision, recall and F1-score, together with train-versus-validation performance to assess generalisation.

Key Takeaways

This project provided practical experience in building an end-to-end classification pipeline, from exploratory analysis and preprocessing to model selection and tuning.

Python Pandas Scikit-learn Machine Learning Classification Random Forest

US Unemployment Forecasting

Time series forecasting using Box-Jenkins methodology and Seasonal ARIMA models in R.

Objective

The objective was to model and forecast the US unemployment rate using classical time series forecasting techniques.

Dataset

The analysis uses the monthly US unemployment rate series from FRED.

Methodology

  • Data exploration
  • Stationarity testing
  • Seasonal differencing
  • Regular differencing
  • ACF and PACF analysis
  • Model identification
  • Model estimation
  • Residual diagnostics
  • Out-of-sample validation

Final Model

The final selected model was:

SARIMA(2,1,1)(1,1,2)₁₂

Several candidate models were compared using information criteria and residual diagnostics before selecting the final specification.

Results

0.187 In-sample RMSE
0.132 In-sample MAE
2.54% In-sample MAPE
0.478 Out-of-sample MASE

Diagnostics

The final model showed no significant residual autocorrelation according to the Ljung-Box diagnostic, supporting the adequacy of the model specification.

Key Takeaways

The project provided practical experience in classical time series analysis, model identification, diagnostics and out-of-sample forecasting.

The MASE value below 1 indicates that the forecasting model performed better than the naive benchmark.

R Time Series SARIMA Forecasting Box-Jenkins FRED

Parkinson's Disease Neural Network Optimization

Metaheuristic optimization of neural network weights for Parkinson's disease classification.

Objective

This project investigated whether metaheuristic optimization algorithms could improve neural network performance when optimizing the network's weights for Parkinson's disease classification.

Dataset

The project uses the UCI Parkinson's dataset, containing voice and acoustic measurements used to distinguish healthy individuals from patients with Parkinson's disease.

The model uses 21 input features for binary classification.

Neural Network

The baseline architecture is a Multi-Layer Perceptron with 21 input features, a hidden layer with 100 ReLU neurons, and a binary output.

The baseline model uses Adam optimisation, while the experimental models optimise the network weights using metaheuristic algorithms.

Optimization Algorithms

Two metaheuristic optimization approaches were compared:

  • Genetic Algorithm (GA) — population-based evolutionary optimization.
  • Grey Wolf Optimizer (GWO) — swarm-based continuous optimization.

L2 Regularization

L2-regularized variants were also investigated to encourage smaller network weights and improve generalisation.

Experimental Setup

  • 21 input features
  • 100-neuron hidden layer
  • ReLU activation
  • Binary classification
  • Genetic Algorithm population of 50
  • Grey Wolf Optimizer pack of 30
  • Convergence analysis
  • Validation and test evaluation

Key Findings

The experiments showed different optimisation behaviours between the two approaches.

  • GA provided strong exploration but converged more slowly.
  • GWO showed faster convergence in the experiments.
  • L2 regularisation helped control overfitting and encouraged smaller weights.
  • The optimized approaches generally improved validation performance compared with the baseline.
